# `DesignPrompt`

This is a design analysis tool built with Next.js, TypeScript, Tailwind CSS, and Google Gemini AI. The application allows users to upload design screenshots or mockups and receive comprehensive implementation prompts powered by AI. It analyzes visual elements, color palettes, typography, layout structure, and component architecture to generate detailed development specifications.

### `Features`:

- Upload design images via drag-and-drop or file selection
- AI-powered design analysis using Google Gemini 2.5 Flash
- Generate detailed implementation prompts from design references
- Extract color palettes with hex codes from uploaded designs
- Identify typography, spacing, and layout patterns
- Component breakdown with suggested HTML/CSS structure
- One-click copy to clipboard for generated prompts
- Dark and light mode theme support
- Responsive design for optimal viewing on all devices

### `Technologies Used`:

- Next.js 15: React framework for production-grade applications
- TypeScript: A strongly typed programming language that builds on JavaScript
- Tailwind CSS v4: Utility-first CSS framework for styling
- Vercel AI SDK: SDK for building AI-powered applications
- Google Gemini AI: Multimodal AI model for image analysis and text generation
- shadcn/ui: High-quality, accessible UI component library
- next-themes: Theme management for dark/light mode support
- Lucide React: Beautiful and consistent icon library
